任务打卡

APiC：最小可解释动力学模型

先用 ODE 做到“能解释、能复现、能做敏感性”，暂不为了高级感直接上 PDE/ABM。

1. 细菌 B(t)

dB/dt = rB·B·(1-B/KB) - cB·B

rB：增殖率；KB：环境承载量；cB：清除率。

2. RBD 抗原 A(t)

dA/dt = kexpr·B - kdeg·A

把“细菌负荷 → 抗原表达 → 抗原降解”显式化。

3. 记忆 T 细胞 T(t)

dT/dt = kact·A·T - dT·T

通过改变 T(0) 或 kact 模拟免疫衰退与抗原错配。

4. 肿瘤 N(t)

dN/dt = gN·N·(1-N/KN) - kkill·T·N

分离“自然增长”和“T 细胞杀伤”两个机制。

什么时候升级？只有研究问题真正涉及细菌空间扩散、肿瘤内部梯度或单细胞异质性时，再考虑 PDE/ABM。

剂量-效应

E(D)=Emax·D^n/(EC50^n + D^n)

重点理解饱和效应：剂量增加并不会无限线性增加效果，因此“最高剂量”通常不等于“最佳剂量”。

数理基础地图

概率直觉 现在学

随机变量、分布、均值/方差、条件概率、独立性、Bayes 直觉。

P(A|B)=P(A∩B)/P(B)

统计推断 现在学

参数估计、置信区间、bootstrap、误差与过拟合。核心认知：参数来自有限数据，因此带有不确定性。

微分方程 APiC 核心

变化率 = 产生/流入 - 损失/流出

最低标准：能看懂每一项为什么存在、方向是什么、单位是否匹配。

敏感性分析 APiC 核心

先做 OAT + 情景分析；有余力再做 Morris；Sobol 不作为 10 月前硬任务。

GLM / Logistic Spillover 后续

logit[P(Y=1)] = β0 + β1X1 + … + βpXp

等 confirmed spillover 标签可靠后再进入真正概率建模。

空间统计 Spillover 后续

Moran's I、空间权重矩阵、空间回归。理解“相邻 grid 并不独立”。

项目练习

APiC 练习 1｜免疫衰退情景

固定其他参数，仅改变 T(0)=100%、50%、20%，比较 72 h 后 N(t)。

交付：时间曲线 + 100–150 字解释结论是否依赖 T(0)。

APiC 练习 2｜最佳剂量

用 Hill 方程表示疗效，再设一个随剂量增加的毒性代价，画 effectiveness / toxicity / net benefit。

APiC 练习 3｜参数可信度

选 8 个参数，标 A/B/C：A=直接实验或高度一致文献；B=相近体系；C=假设/宽范围。优先对 C 级参数做敏感性。

Spillover 练习 1｜事件去重

随机抽 30 个 event，比较原始 event 数与 canonical event 数；设计 duplicate_group_id 与 same/probable_same/distinct。

Spillover 练习 2｜Risk v1

Risk=w1·Suitability+w2·Overlap+w3·exp(-d/λ)+w4·HFP

做 3 组权重敏感性比较；输出叫 risk index，不叫 probability。

Spillover：三阶段路线

Risk v1

Host suitability + overlap + distance-decay + HFP。

先做相对风险指数。

Risk v2

canonical event + evidence quality + 独立验证。

解决重复统计和标签质量。

Risk v3

Logistic / Poisson / NB / spatial model。

可靠标签后再做概率化。

事件数据的核心问题：同一 biological event 可能被多篇论文重复报道；病原在宿主中被检测到不等于明确 spillover；监测强度和发表强度也会制造空间偏差。
字段建议
canonical_event_id一个真实事件的唯一 ID
duplicate_group_id聚合同一候选 biological event 的多篇文献
spillover_evidenceconfirmed / probable / association-only
evidence_pmids[]保留全部证据，但不把 PMID 数当事件数
confidencehost / pathogen / location / time / event identity 分开记录
