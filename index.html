通用数理学习地图

1. 概率直觉

随机变量、分布、均值/方差、条件概率、Bayes 直觉。

P(A|B)=P(A∩B)/P(B)

用于理解“观察到的证据”与“真实过程”之间的差别。

2. 统计推断

参数估计、置信区间、bootstrap、假设检验、抽样偏倚。

用于判断结果有多稳定，而不是只看一个点估计。

3. 回归 / GLM

logit[P(Y=1)] = β0 + β1X1 + … + βpXp

适合二分类风险、计数模型和多变量效应分析。

4. ODE 动力学

dX/dt = production - loss + inflow - outflow

适合研究随时间变化的生物量、细胞群、药效和传播动力学。

5. 剂量-效应

E(D)=Emax·D^n/(EC50^n+D^n)

学习饱和、半最大效应和非线性响应。

6. 敏感性分析

先 OAT / 情景分析，再根据需要做 Morris / Sobol。

解决“哪些参数最影响结论？”

7. 距离与相似度

Euclidean、Manhattan、cosine、Jaccard、加权距离、距离衰减。

w(d)=exp(-d/λ)

8. 遗传 / 系统发育距离

理解替换率、p-distance、模型校正距离、树上 patristic distance。

敏感项目只需在本地配置中指定“遗传距离”，公开页不需要具体物种或序列。

9. 空间统计

空间邻接、Moran's I、空间自相关、空间回归。

解决相邻空间单元并非独立样本的问题。

10. 风险评分 vs 概率

人为加权得到的 0–1 分数通常是 relative risk index；只有经过统计拟合与校准后才适合解释为 probability。
