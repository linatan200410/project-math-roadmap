# Project Math Roadmap

项目导向数理训练营：**APiC 优先 × Spillover 后续**。

## 当前目标
- 2026 年 10 月中旬前完成 APiC 干实验核心建模与数理补足
- 建立概率统计、ODE、剂量-效应、参数估计、敏感性分析的最小闭环
- 之后迁移到野生动物病原 Spillover 的事件去重、风险指数与空间统计

## 网页功能
- 固定导航栏
- 学习任务打卡与浏览器本地保存
- 概念测试与即时反馈
- APiC / Spillover 项目练习
- 练习笔记 localStorage 保存
- 学习进度 JSON 导出

## GitHub Pages
本仓库为纯静态网页。启用 GitHub Pages 后，入口为 `index.html`。

> 注意：网页中的学习进度保存在当前浏览器 localStorage；换浏览器或清理站点数据前建议先导出进度。
