# Research Math Roadmap

一个公开的、项目导向的数理学习网页。公开仓库只包含通用数学/统计/建模框架；具体科研项目背景、任务优先级、测试与练习上下文可在浏览器本地配置。

## 设计原则

- **公开部分**：概率统计、ODE、剂量-效应、敏感性分析、距离与相似度、遗传/系统发育距离、空间统计、风险评分与概率模型。
- **本地部分**：项目名称、截止日、脱敏背景、当前基础、所需数学主题、学习打卡、测试结果和练习笔记。
- 本地配置存储在浏览器 `localStorage`；支持导入 `.txt/.md/.json/.csv` 项目说明，文件仅在浏览器本地读取。
- 不建议把未公开项目细节、真实病原/宿主信息、序列、参数表、遗传距离数据或实验结果写入公开仓库。

## 使用方式

打开网页后：

1. 在“本地项目配置”中填写一个脱敏项目摘要。
2. 选择需要补足的数学主题。
3. 设置截止日。
4. 点击“生成学习方案”。
5. 使用任务打卡、测试题和项目练习。
6. 如需备份，导出本地配置 JSON。
